1️⃣ 관리자 대시보드

📊 대시보드 메뉴에서 시스템 전체 현황을 한눈에 파악합니다.

  • 📈 전체 통계: 등록된 매장, 활성 작업, 완료된 매장 등
  • 🔄 전체 진행 상황: 리뷰 완료율, 이미지 완료율, 평균 소요 시간
  • 👥 사용자별 현황: 팀별 매장 수 및 완료율

2️⃣ 매장 관리

🏪 매장 등록 메뉴에서 모든 사용자의 매장을 관리합니다.

  • 새 매장 등록 (모든 사용자 대신 가능)
  • 기존 매장 수정/삭제
  • 사용자별 매장 필터링
  • 일괄 작업 (대량 등록, 대량 삭제)

3️⃣ 모니터링 및 분석

📋 작업 관리에서 모든 사용자의 매장 작업 상태를 모니터링합니다.

📖 리뷰 메뉴에서 전체 사용자의 리뷰 현황을 분석합니다.

  • 소속: 어느 팀에 속하는 매장인지 표시
  • 링크 입력: Google Maps 링크 수동 입력
  • 링크 추출: Google Maps에서 자동 추출

4️⃣ 배포 및 자동화

🚀 배포 메뉴에서 자동 배포 스케줄을 관리합니다.

  • 📅 스케줄 관리: 배포 시간 설정, 간격 조정
  • ⏱️ 수동 배포: 즉시 배포, 예약 배포
  • 📊 배포 로그: 성공/실패 기록 확인

5️⃣ 사용자 및 계정 관리

👥 계정 관리

  • 사용자 추가 (로그인 ID, 비밀번호, 역할, 팀)
  • 사용자 수정 (비밀번호 재설정, 역할 변경)
  • 사용자 삭제 (데이터 보관 옵션)

🔐 Google 계정

  • 계정 추가 (이메일, 비밀번호, 2FA, API 키)
  • 계정 상태 모니터링 (로그인 성공/실패, 마지막 사용 시간)
  • 계정 삭제 (백업 생성 옵션)

6️⃣ 시스템 설정

  • 보안 설정 (비밀번호 정책, 세션 타임아웃)
  • 기능 토글 (Agency 계정 생성 허용/금지, 자동 배포 활성화)
  • 알림 설정 (작업 완료 알림, 실패 알림, 일일 리포트)

7️⃣ 트러블슈팅

문제 원인 해결 방법
배포 실패 Google 계정 로그인 오류 🔐 Google 계정 관리 → 계정 재설정
