1️⃣ 매장 등록 가이드

메뉴: 🏪 매장 등록

새로운 매장을 시스템에 등록하여 Google Maps 리뷰 자동화를 시작할 수 있습니다.

Step 1: 매장 정보 입력

  • 매장명 (필수): 고객에게 보이는 매장 이름
  • 주소 (필수): Google Maps에 표시될 정확한 위치
  • 리뷰 메시지 (필수): 리뷰 가이드를 작성 후 AI로 생성한 원고
  • 이미지 (선택): 최대 2개까지 업로드 가능

Step 2: 원고 작성 (필수)

원고 작성 3단계:
  1. 리뷰 가이드 작성: 매장의 주요 특징, 경험, 장점을 정리합니다.
  2. AI로 원고 생성: ChatGPT, Gemini 등을 활용하여 전문적인 원고를 생성합니다.
  3. 최종 검수: 생성된 원고의 맞춤법과 자연스러운 표현을 확인합니다.

Step 3: 발행 주기 설정

  • 일일 발행 횟수: 1일에 얼마나 자주 발행할지 (기본: 1회/일)
  • 총 발행 횟수: 전체 며칠 동안 발행할지 (기본: 1회)

Step 4: 등록 완료

모든 정보를 입력한 후 [등록] 버튼을 클릭하면:

  1. 등록 완료 메시지 표시
  2. 📋 작업 관리 메뉴에서 상태 확인 가능
  3. 설정된 시간에 자동 발행
  4. Google Maps에 리뷰 + 이미지 게시

2️⃣ 작업 진행 현황 가이드

메뉴: 📋 작업 관리

등록한 매장의 작업 진행 상황을 실시간으로 확인할 수 있습니다.

상태별 아이콘

상태 의미
⏹️ 없음 아직 작업 대기 중
⏳ 승인중 리뷰/이미지 발행 진행 중
✅ 완료 발행 완료됨
❌ 실패 발행 실패 (로그 확인 필요)

추가 이미지 업로드

매장 등록 후 추가 이미지를 업로드할 수 있습니다:

  1. 작업 관리 → 해당 매장 클릭
  2. [📸 이미지 업로드] 버튼 클릭
  3. 파일 선택 후 업로드 (최대 2개)
  4. 여러 번 반복 가능

3️⃣ 리뷰 가이드

메뉴: 📖 리뷰

최종 승인된 매장의 리뷰를 확인할 수 있습니다.

리뷰 링크 확인

리뷰 탭의 "리뷰상세확인" 컬럼에서:

  • [리뷰보기 ↗] 링크를 클릭하면 Google Maps의 실제 리뷰를 확인할 수 있습니다.
  • 등록된 이미지와 함께 발행된 리뷰를 확인 가능합니다.

📊 전체 워크플로우

📝 0단계: 발행 콘텐츠 준비 (필수)
  ├─ 리뷰 가이드 작성
  ├─ AI로 원고 생성
  ├─ 최종 검수
  └─ 이미지 준비 (2개)

        ↓

📍 1단계: 매장 등록
  ├─ 매장명, 주소 입력
  ├─ AI 원고 입력 (필수)
  ├─ 이미지 업로드 (선택)
  ├─ 발행 주기 설정
  └─ [등록] 버튼 클릭

        ↓

📋 2단계: 작업 진행 모니터링
  ├─ 리뷰 상태 확인
  ├─ 이미지 상태 확인
  └─ 필요시 추가 이미지 업로드

        ↓

📖 3단계: 최종 확인
  └─ 리뷰보기 링크로 Google Maps 확인

        ↓

✅ Google Maps에 발행 완료!

❓ 자주 묻는 질문

Q: 원고를 꼭 AI로 생성해야 하나요?

A: 네, 리뷰 메시지는 필수 입력 항목입니다. 직접 작성하시거나 AI 도구를 활용하여 작성해주세요.

Q: 이미지는 몇 개까지 업로드 가능한가요?

A: 한 번에 최대 2개까지 업로드 가능하며, 여러 번 반복하여 더 많은 이미지를 추가할 수 있습니다.

Q: 발행 후 내용을 수정할 수 있나요?

A: 발행된 리뷰는 직접 Google Maps에서 수정해야 합니다. 새로운 매장을 다시 등록하는 방식으로 진행해주세요.
